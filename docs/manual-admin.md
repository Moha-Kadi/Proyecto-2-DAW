# Manual de Administrador - BeinScore

## Acceso al panel
1. Iniciar sesion con una cuenta con rol `admin`
2. Ir a "Admin" en el menu del avatar

## Gestion de usuarios
El panel muestra una tabla con todos los usuarios registrados (excepto el admin principal). Para cada usuario se ve: nombre, email, rol y estado.

### Activar / Desactivar
Pulsar el boton "Desactivar" o "Activar" segun el estado actual. La cuenta desactivada no podra iniciar sesion.

### Borrar usuario
Pulsar "Borrar" y confirmar. La cuenta se elimina permanentemente.

## Notas
- No se puede desactivar ni borrar la cuenta del admin que esta usando el panel
- El admin principal (username "admin") no aparece en la tabla
