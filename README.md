# BeinScore

Plataforma de resultados deportivos en tiempo real. Sigue partidos de las 5 grandes ligas, consulta clasificaciones y estadisticas detalladas.

## Requisitos
- Docker y Docker Compose

## Instalacion rapida
```bash
git clone https://github.com/Moha-Kadi/Proyecto-2-DAW.git
cd Proyecto-2-DAW
cp .env.example .env
docker compose up -d
```
Abrir http://localhost

## Tecnologias
Python · FastAPI · Angular 21 · Tailwind CSS · MongoDB · Nginx · Docker
